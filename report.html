1. Web Architecture & Workflow Explanation

Question: อธิบายบทบาทของ Browser, GitHub Pages, HTML/CSS/Bootstrap และ HTTP ตั้งแต่ผู้ใช้เปิด URL จนกระทั่งเห็นหน้าเว็บไซต์ พร้อมลำดับขั้นตอนการทำงาน

Answer:

  • Browser: ทำหน้าที่รับ URL จากผู้ใช้งาน ส่งคำขอไปยังเซิร์ฟเวอร์ และประมวลผลเรนเดอร์โค้ด HTML/CSS/Bootstrap ออกมาเป็นหน้าเว็บไซต์ให้ผู้ใช้มองเห็น
  • GitHub Pages: ทำหน้าที่เป็น Web Server จัดเก็บไฟล์โปรเจกต์ทั้งหมด (เช่น index.html, style.css, โฟลเดอร์มีเดีย) และให้บริการส่งมอบไฟล์ผ่านระบบออนไลน์
  • HTML / CSS / Bootstrap: HTML ใช้สร้างโครงสร้างเนื้อหาหลัก, CSS ตกแต่งสไตล์และสีสัน, และ Bootstrap (ผ่าน CDN) ช่วยจัดการระบบ Grid และ Responsive Layout ให้แสดงผลสวยงามทุกหน้าจอ
  • HTTP: โปรโตคอลสื่อสารข้อมูลผ่านเครือข่ายอินเทอร์เน็ต ใช้รับส่งข้อมูลระหว่าง Browser (Client) กับ GitHub Pages (Server)

ลำดับขั้นตอนการทำงาน:

  1. ผู้ใช้พิมพ์ URL ของเว็บไซต์บน Browser
  2. Browser ส่งคำขอ (HTTP Request) ผ่านเครือข่ายไปยัง GitHub Pages Server
  3. Server ค้นหาและส่งไฟล์โปรเจกต์ (HTML, CSS, รูปภาพ) กลับมายัง Browser (HTTP Response)
  4. Browser ทำการดาวน์โหลดและแปลความหมายโค้ด แล้วเรนเดอร์ออกมาเป็นหน้าเว็บ portfolio ให้ผู้ใช้ใช้งาน

2. Search & Generative AI Reflection

Question: กรณีศึกษาการใช้ Search หรือ Generative AI ช่วยพัฒนา A2 (ใช้แก้ปัญหาอะไร, AI เสนออะไร, ตรวจสอบอย่างไร, ตัดสินใจใช้อย่างไร)

Answer:

  • ใช้เพื่อแก้ปัญหาอะไร: ต้องการจัดหน้า Navbar ให้อยู่แถวเดียวกับหัวข้อหลักแบบกะทัดรัด (ชิดขวาบนจอคอมพิวเตอร์) โดยไม่ให้แถบเมนูลากยาวเต็มหน้าจอ
  • AI หรือแหล่งข้อมูลเสนออะไร: AI แนะนำให้ใช้ Bootstrap Grid System แบ่งคอลัมน์ด้วย row และ col-md-8 กับ col-md-4 พร้อมใช้คลาสจัดตำแหน่ง text-md-end และโครงสร้างปุ่มแบบ d-inline-flex gap-2
  • นักศึกษาตรวจสอบข้อเสนอนั้นอย่างไร: ลองปรับใช้โค้ดนั้นในไฟล์ index.html ของตัวเอง แล้วเปิดพรีวิวดูผลลัพธ์ผ่านเบราว์เซอร์ รวมถึงลองย่อ-ขยายหน้าจอเพื่อตรวจสอบ Responsive ของผลลัพธ์
  • ตัดสินใจใช้อย่างไร: นำโครงสร้าง Grid และคลาสจัดตำแหน่งมาใช้จริงเพราะช่วยแก้ปัญหาได้ตรงจุด แต่ปรับแต่งสีปุ่มและเอฟเฟกต์ Hover เพิ่มเติมเองในไฟล์ style.css เพื่อให้คุมโทนสีเข้ากับธีมหลักของพอร์ตเดิมที่เคยส่งไปในงานแรก
